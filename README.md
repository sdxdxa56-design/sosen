# صفحة مشاركة صورة وموقع بموافقة صاحب الجهاز

## المتطلبات
- Node.js 20 أو أحدث
- حساب SMTP صالح لدى مزود بريد
- استضافة HTTPS؛ المتصفحات تشترط سياقاً آمناً لاستخدام الكاميرا والموقع (localhost صالح للتطوير)

## التشغيل محلياً
1. انسخ `.env.example` إلى `.env`.
2. أدخل إعدادات SMTP الحقيقية، واترك `MAIL_TO=sdxdxa56@gmail.com`.
3. نفّذ `npm install`.
4. نفّذ `npm start`.
5. افتح `http://localhost:3000`.

## النشر
ارفع المشروع إلى استضافة Node.js تدعم HTTPS، واضبط متغيرات البيئة من لوحة الاستضافة. لا ترفع ملف `.env` ولا تضع بيانات SMTP في ملفات الواجهة الأمامية.

## السلوك
- يطلب إذن الكاميرا الأمامية صراحةً.
- يعرض معاينة مباشرة قبل الالتقاط.
- يطلب إذن الموقع عند الضغط على زر المشاركة.
- يرسل الصورة والإحداثيات إلى البريد المحدد.
- لا توجد آلية تصوير أو تتبع خفي.

## ملاحظات
- لا يعمل الوصول للكاميرا والموقع من رابط HTTP عام؛ استخدم HTTPS.
- اضبط حدود الطلبات ومعدل الإرسال وحماية إساءة الاستخدام قبل نشره على الإنترنت.
